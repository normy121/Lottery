# Walk Of Life Lottery Calculator

A static English-language calculator for the chance of winning at least once when buying 1–35 lottery tickets.

## Formula

The per-ticket chance is the 3% base chance plus selected additive bonuses. For `n` tickets, the displayed chance is `1 - (1 - p)^n`.

## Publish with GitHub Pages

Push this folder to a GitHub repository, then in the repository settings choose **Pages** → **Deploy from a branch** → select `main` and `/ (root)`.
